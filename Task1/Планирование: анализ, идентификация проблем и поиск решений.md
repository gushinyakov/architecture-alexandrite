# Планирование: анализ, идентификация проблем и поиск решений

Основные проблемы
- Медленная работа системы MES: долгое время загрузки заказов и страницы в целом
- Проблема с обработкой заказов: задержка и потеря заказов
- Долгое время поставки сервисов на прод (time-to-market): Маленький штат QA, только unit тестирование, отсутвие автотестов, нет выделеной роли тех поддержки

В ближайшие пол года компании необходимо сосредоточиться на observability продукта, для понимая узких мест в сервисах.\ 
На основе накопленных метрик можно будет выстроить стратегический план и выявить потребности пользователей.\
Также стоит уделить внимание настройки кеширования, что даст видимый результат для пользователей и позволит масштабировать сервисы.

Выделил бы три задачи
- Настройка серверного кеширования Read-Through, Write-Through
- Настройка трейсинга для отслеживания хода выполнения заказов
- Настройка монторинга, prometheus, grafana, метрик производительности
